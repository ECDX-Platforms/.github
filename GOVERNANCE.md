# Governance

ECDX Platforms is maintained as a shared technical knowledge base for Microsoft Business Applications and related platform engineering.

## Ownership

Each repository should have an identified maintainer or subject owner. Owners are responsible for keeping content accurate, reviewing contributions, and identifying obsolete guidance.

## Decisions

- Small documentation corrections can be merged through normal review.
- Changes affecting standards, security, architecture, or organizational direction should be discussed in an issue or proposal before implementation.
- Decisions should record the chosen approach and its rationale when the impact is significant.

## Repository Lifecycle

New repositories should have a clear purpose, owner, and maintenance expectation. Repositories may be consolidated, archived, or removed when they duplicate content, have no active owner, or no longer support the organization's goals.

## Scope

This document describes the GitHub organization working model. It does not replace Tieto policies, customer commitments, or formal security and compliance controls.
