# Support

## Where to Ask

- Use issues for documentation corrections, reproducible problems, and improvement proposals.
- Use discussions or the approved internal team channel for questions and design conversations, when enabled.
- Use the organization's internal support and security processes for incidents, access requests, customer matters, or confidential information.

## Before Opening an Issue

- Search existing issues and documentation.
- Include the relevant repository, platform, and version where applicable.
- Provide reproduction steps, expected behavior, and observed behavior.
- Remove secrets, customer data, and other confidential information.
